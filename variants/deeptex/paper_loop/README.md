# paper_loop/ - the shared skeleton

Every DeepTextures training run of ours is **the paper's loop plus one
experiment's hooks**.

| file | what it is |
|---|---|
| `loop.py` | `external/DeepTextures/train_esrgan.py`, top to bottom, with hook calls inserted. No other line differs (`upstream.diff`). |
| `psnr_loop.py` | `external/esrgan-tf2/train_psnr.py` (the donor's PSNR stage) the same way (`psnr_upstream.diff`). Drives DeepTextures' `modules`, as the old trainer's `--stage psnr` did. |
| `hooks.py` | `Hooks` / `PsnrHooks`: one method per replaced upstream line; every default **is** that line, kept verbatim. |
| `main.py` | `--experiment {paper,fixed,render}` → build the hook bundle, run the loop. |
| `upstream.diff`, `psnr_upstream.diff` | generated by `variants/tests/l0_skeleton.py --write`. |

## What the old trainer did differently and is kept / changed

* **Kept, byte for byte:** every log prefix, every `[fatal]` message and exit
  code, the checkpoint object names (`step`, `model`, `discriminator`,
  `optimizer_G/D`, `optimizer`), the config keys, the RNG consumption order
  (seed → `check_gpu` → G → D → dataset → optimizers → `ContentLoss` →
  `RenderLoss`). L1 checks this to the bit.
* **TensorBoard tags** are now upstream's: the ESRGAN loop writes
  `train_esrgan.py:131-144`'s, the PSNR loop the donor's `loss/*`,
  `learning_rate` (the old trainer wrote `loss_G/*`, `learning_rate_G` for
  PSNR). Our own scalars (`val/*`, `monitor/render_l21`) go through a second
  writer to the same log directory. Event files are not a compared contract.
* **Render-arm flags** `--losses`, `--shuffle` accept only `upstream` / `off`
  (the only values `run_deeptex.ps1` ever passed); the fixed arm has no render
  flags, so `--w-render` on it is an argparse error (exit 2) where the old
  trainer exited 8 - the same exit-8 message now comes from
  `--experiment render` on a non-grouped config.
* A grouped config under `--experiment fixed` is refused (exit 8).
