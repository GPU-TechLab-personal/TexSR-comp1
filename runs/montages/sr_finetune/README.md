## Before reading

- Map montages and map metrics show one checkpoint per fine-tuned arm (step 40000); render and perceptual
  metrics cover every step in the table above; `checkpoints/<arm>/` follows the colour from step 0 (the
  official weights) through every saved checkpoint.
- The 1-channel maps (roughness, metallic, height) went in as three equal channels and are the mean of the
  three output channels; how far those channels drifted apart is `channel_spread` in each `sr_manifest.json`.
- The `render` column of `maps/<material>.png` is image SR of MatUp's LR render; `renders/render_<material>.png`
  and `renders/overview_render_pred.png` render each method's predicted SVBRDF with MatUp's renderer.
- The sheets in `dt_only/` and `vs_render_loss/` are titled "DeepTextures arms only" (the script was written
  for those); their SR rows are the official ESRGAN / SwinIR, as labelled.

|---|---|
| `maps/<material>.png`, `maps/overview_<map>.png` | map montages: LR / bilinear / MatUp / DeepTextures / SR arms / GT (deeptex_arms_report.py) |
| `summary.md`, `per_material.md`, `metrics_long.csv`, `report.json` | map-space metrics |
| `renders/render_<material>.png` | renders of the predicted SVBRDFs; local only (.gitignore), regenerated by -Stage eval |
| `renders/overview_render_pred.png`, `render_summary.md` | render-space overview and metrics (svbrdf_render_eval.py) |
| `perceptual_summary.md`, `perceptual_report.json` | LPIPS / FLIP on those renders (svbrdf_perceptual_eval.py) |
| `dt_only/` | the SR arms against each other and GT only (deeptex_dt_montage.py) |
| `vs_render_loss/` | the fine-tuned SR arms (step 40000) beside DeepTextures (matsynth_all) / DeepTextures grouped (R0a) / DeepTextures grouped (R0b) / DeepTextures + render loss (R1) and GT (deeptex_dt_montage.py) |
| `checkpoints/<arm>/` | colour drift per checkpoint: `drift.md` (baseColor), `drift_normal.md`, `0844_syntetic_foam` sheets (sr_finetune/drift.py) |
